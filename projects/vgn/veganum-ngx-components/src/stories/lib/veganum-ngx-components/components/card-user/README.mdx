# VGN CARD USER

Componente para mostrar card de usuario.

## ¿Que hace este componente?

Muestra informacion basica de un usuario en formato card.

## Uso:

#### Importacion
```ts
import {
  CardUser,
  UserName,
  CardUserDto,
} from '@vgn/veganum-ngx-components/components/card-user';

  @Component({
  standalone: true,
  imports: [CardUser],
})
```
#### HTML
```html
  <vgn-card-user [user]="user" [check]="true" cardType="avatar" (checked)="onUserCheck($event)" ></vgn-card-user>
```
